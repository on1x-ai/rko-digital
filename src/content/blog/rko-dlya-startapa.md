## Почему стартапу нужен особый счёт

Обычный корпоративный счёт не подходит для стартапа, потому что:

- **Приём инвестиций** — нужен валютный контроль для зарубежных инвесторов
- **Быстрые платежи** — поставщики и подрядчики ждут оплаты в течение дня
- **Интеграции** — API для автоматизации бухгалтерии и выплат
- **Масштабирование** — счёт должен работать при росте оборота в 10–100 раз

## Топ‑3 банка для стартапов в 2026

### 1. Альфа‑Банк — для привлечения инвестиций
- **Открытие**: 0 ₽, 1 день
- **Обслуживание**: 0 ₽ при обороте до 1 млн ₽/мес, потом 990 ₽/мес
- **Инвестиции**: Поддержка SAFE, Convertible Notes, прямых инвестиций
- **Валютный контроль**: Продвинутый, с персональным менеджером
- **Интеграции**: API для 1С, «Моё дело», Confluence

**Лучше всего подходит**: Стартапам, которые планируют привлекать зарубежные инвестиции.

### 2. Т‑Банк — для быстрого старта
- **Открытие**: 0 ₽, 1 день онлайн
- **Обслуживание**: 0 ₽ первые 6 месяцев, потом 490 ₽/мес
- **Инвестиции**: Упрощённый процесс для российских инвесторов
- **Валютный контроль**: Базовый, через чат‑поддержку
- **Интеграции**: Готовые шаблоны для Яндекс.Облака, Tilda

**Лучше всего подходит**: Ранним стартапам (pre‑seed, seed) с оборотом до 5 млн ₽/мес.

### 3. Точка — для e‑commerce и SaaS
- **Открытие**: 0 ₽, 1 день
- **Обслуживание**: 0 ₽ (тариф «Ноль»), потом 950 ₽/мес
- **Процент на остаток**: до 7% годовых
- **Эквайринг**: Интеграция с ЮKassa, CloudPayments, Stripe
- **API**: Полноценный REST API для автоматизации

**Лучше всего подходит**: SaaS‑стартапам и e‑commerce проектам с recurring‑доходами.

## Как открыть счёт для ООО

### 1. Подготовка документов
- **Устав** ООО (оригинал или нотариальная копия)
- **Решение/протокол** о создании
- **Свидетельство ОГРН** и **ИНН**
- **Паспорта** учредителей и директора (все страницы)
- **Договор аренды** офиса или **заявление по форме 26.2-7** (если нет юрадреса)

### 2. Выбор тарифа
- **Стартовый**: 0–5 млн ₽/мес оборот (Т‑Банк, Точка)
- **Базовый**: 5–20 млн ₽/мес (Альфа‑Банк, Т‑Банк «Про»)
- **Профессиональный**: 20+ млн ₽/мес (Альфа‑Банк «Премиум»)

### 3. Подача заявки
- **Онлайн**: Через сайт банка (20–30 минут)
- **Видеоидентификация**: 10–15 минут с сотрудником банка
- **Документы**: Загружаются в личный кабинет

### 4. Получение доступа
- **1–3 рабочих дня** — счёт открыт
- **Ещё 1–2 дня** — подключение интернет‑банка и API
- **Неделя** — настройка эквайринга и интеграций

## Как принять инвестиции без блокировок

### Для российских инвесторов:
1. **Договор инвестирования** (SAFE, Convertible Note, доля)
2. **Решение общего собрания** о принятии инвестиций
3. **Уведомление банка** (можно после получения денег)

### Для иностранных инвесторов:
1. **Инвестиционный договор** на английском (желательно с apostille)
2. **Подтверждение происхождения средств** (выписка со счёта инвестора)
3. **Пояснительное письмо** от директора стартапа (на русском и английском)
4. **Загрузка в банк** через личный кабинет

**Срок проверки**: 3–10 рабочих дней для сумм от $50 000.

## Как избежать блокировок по 115‑ФЗ

### Красные флаги для банка:
- **Частые переводы** физлицам (особенно на карты других банков)
- **Круглые суммы** (100 000 ₽, 500 000 ₽)
- **Переводы в криптовалюту** или на криптобиржи
- **Отсутствие договоров** с контрагентами

### Что делать, чтобы не попасть под блокировку:
1. **Все платежи** должны быть по договорам
2. **Выплаты фрилансерам** — только по актам выполненных работ
3. **Зарплата учредителям** — официально, с налогами
4. **Крупные суммы** (от 600 000 ₽) — дробить на несколько платежей
5. **Криптовалюта** — не использовать для бизнес‑расчётов

## Интеграции, которые нужны стартапу

### Обязательные:
- **Бухгалтерия**: «Моё дело», «Контур.Эльба», 1С
- **Платёжный шлюз**: ЮKassa, CloudPayments, Stripe (для зарубежных платежей)
- **ERP**: Megaplan, Bitrix24 (если больше 5 сотрудников)

### Рекомендуемые:
- **Аналитика**: API для выгрузки транзакций в Google Sheets
- **Автоматизация выплат**: для фрилансеров и подрядчиков
- **Уведомления**: Telegram‑бот о поступлениях и списаниях

- [ ] Готовы договоры с первыми клиентами/инвесторами
- [ ] Есть понимание, какие интеграции нужны

## Дальнейшие шаги

1. **Соберите документы** (список выше)
2. **Выберите банк** по своим потребностям
3. **Подайте заявку онлайн** (20–30 минут)
4. **Пройдите видеоидентификацию** (10–15 минут)
5. **Настройте интеграции** (1–2 дня)
6. **Примите первые платежи** и инвестиции

**Не откладывайте**. Без расчётного счёта вы не сможете принимать оплату от клиентов и инвестиции. Первые 6 месяцев обычно бесплатные — используйте это время, чтобы вырасти.
