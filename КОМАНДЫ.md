# 🚀 Командная строка для запуска бота

## 📁 Перейдите в папку проекта:
```cmd
cd C:\Projects\rko-site
```

## 📦 Установите зависимости:
```cmd
pip install aiogram python-dotenv
```

## 🔧 Настройте окружение (если нужно):
```cmd
copy .env.example .env
```
Отредактируйте `.env` если хотите использовать другой токен.

## 🏃 Запустите бота:
```cmd
cd bot
python main.py
```

## 🧪 Протестируйте логику:
```cmd
cd C:\Projects\rko-site
python test_recommendations.py
```

## 📋 Быстрые команды:
```cmd
# Из любой папки:
cd /d C:\Projects\rko-site\bot && python main.py

# Или PowerShell:
Set-Location C:\Projects\rko-site\bot; python main.py

# Проверить зависимости:
pip list | findstr aiogram
```

## 💡 Если проблемы:
```cmd
# Проверить Python версию:
python --version

# Проверить установленные пакеты:
pip freeze | findstr aiogram

# Переустановить зависимости:
pip uninstall aiogram python-dotenv -y
pip install aiogram python-dotenv
```
