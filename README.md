# Telegram Bot для подбора расчётного счёта (РКО)

Умный бот-консультант для подбора расчётного счёта digital-предпринимателям. Задаёт 5–7 вопросов, анализирует ситуацию и рекомендует банк с партнёрской ссылкой.

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка бота
1. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram
2. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Вставьте свой токен в `.env`:
   ```
   BOT_TOKEN=ваш_токен_от_BotFather
   ```

### 3. Запуск бота
```bash
python bot/main.py
```

## 🧠 Логика работы

Бот задаёт вопросы по цепочке:
1. Статус бизнеса (ИП/ООО/планирует/самозанятый)
2. Сфера деятельности
3. Оборот в месяц
4. Иностранные платежи
5. Приоритеты (цена/надёжность/простота/валюта)
6. Эквайринг (опционально)
7. Готовность регистрировать ИП (если нужно)

На основе ответов чистая функция `recommend_bank()` выбирает банк по правилам:
- Нет ИП + готов регистрироваться → Альфа/ВТБ РегБиз
- Самозанятый → рекомендация по регистрации ИП
- Есть ИП + малый оборот → Точка/Локо
- Есть ИП + средний+ оборот → Альфа
- Валюта/зарубежные платежи → Альфа

## 🔗 Партнёрские офферы

Используются только ссылки из ТЗ:
- **Точка** — для старта и малого оборота
- **Альфа-Банк** — для среднего+ оборота и валюты
- **Локо-Банк** — минимальные требования
- **Альфа/ВТБ РегБиз** — регистрация + счёт
- **Ак Барс, БСПБ** — региональные варианты

## 🧪 Тестовые сценарии

Протестируйте 5 путей:

1. **Нет ИП, готов регистрироваться**
   - Ответы: Нет → IT → до 100 тыс → Нет → Подешевле → (пропуск) → Да
   - Ожидаем: Альфа РегБиз

2. **Есть ИП, малый оборот**
   - Ответы: Да → Фриланс → до 100 тыс → Нет → Минимум возни
   - Ожидаем: Точка + Локо (запасной)

3. **Есть ИП, агентство, средний оборот**
   - Ответы: Да → Агентство → 300 тыс – 1 млн → Иногда → Надёжный банк
   - Ожидаем: Альфа РКО

4. **Самозанятый**
   - Ответы: Самозанятый → Другое → Пока почти нет → Нет → Подешевле
   - Ожидаем: Альфа РегБиз + рекомендация по ИП

5. **Нужны зарубежные платежи**
   - Ответы: Да → IT → 100–300 тыс → Регулярно → Валюта
   - Ожидаем: Альфа РКО

## 📊 Логирование

Бот логирует:
- Запуск/остановку
- Ответы пользователей (без персональных данных)
- Ошибки

Логи выводятся в консоль.

## 🔄 Команды

- `/start` — приветствие и главное меню
- Кнопки в меню:
  - 🎯 Подобрать банк — начать опрос
  - ℹ️ Как это работает — информация
  - 🔄 Пройти ещё раз — перезапуск
  - 🏠 В главное меню — возврат

## 🛡️ Безопасность

- Не запрашивает email, телефон, ФИО
- Не хранит персональные данные
- Использует только проверенные партнёрские ссылки
- Включает дисклеймеры о условиях банков

## 🐛 Отладка

Если бот не отвечает:
1. Проверьте токен в `.env`
2. Убедитесь, что бот не заблокирован
3. Проверьте логи в консоли
4. Убедитесь, что установлены все зависимости
